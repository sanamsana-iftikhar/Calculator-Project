# Simple Calculator

A simple calculator project built using HTML, CSS, and JavaScript.  
This calculator can perform basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear button to reset calculation
- Simple and user-friendly interface

## Technologies And Languages Used
- HTML
- CSS
- JavaScript
- VS STUDIO 

## How to Run
1. Download or clone this repository.
2. Open the `index.html` file in your browser.
3. Start using the calculator.
